# opencode-docker

This repository provides a Docker image based on `ghcr.io/anomalyco/opencode` with a local Ollama service configured to use the `qwen2.5-coder:7b` model.

## Features

- Uses the official `ghcr.io/anomalyco/opencode` image as the base.
- Runs Ollama as a separate container for compatibility and stability.
- Pulls the `qwen2.5-coder:7b` model automatically.
- Configures OpenCode to connect to the local Ollama API.
- Shares a host workspace directory for generated Terraform and other code.

## Build

```bash
docker compose build
```

## Run

```bash
docker compose up -d
```

Then open:
- OpenCode UI: http://localhost:3000
- Ollama API: http://localhost:11434

## Shared code directory

The compose file mounts:
- `./workspace` -> `/workspace`
- `./data` -> `/root/.local/share/opencode`

Any code generated by OpenCode is visible on the host in `./workspace`.

## Notes

- This setup uses `qwen2.5-coder:7b`, which is a strong code-focused Ollama model for Terraform and infrastructure generation.
- If you want a stronger but heavier model, replace `qwen2.5-coder:7b` with `qwen2.5-coder:14b`.
