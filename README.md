# opencode-docker

This repository provides a Docker image based on `ghcr.io/anomalyco/opencode` with a local Ollama service configured to use the `qwen3:8b` model.

## Features

- Uses the official `ghcr.io/anomalyco/opencode` image as the base.
- Runs Ollama as a separate container for compatibility and stability.
- Pulls the `qwen3:8b` model automatically.
- Configures OpenCode to connect to the local Ollama API.
- Shares a host workspace directory for generated Terraform and other code.

## Build

```bash
docker compose build
```

## Run

```bash
docker compose up -d
```

Then open the app at:
- http://localhost:3000

The container listens on `0.0.0.0:4096` internally and is mapped to host port `3000` in Docker Compose.

## Shared code directory

The compose file mounts:
- `./workspace` -> `/workspace`
- `./data` -> `/root/.local/share/opencode`

Any code generated by OpenCode is visible on the host in `./workspace`.
